    Browser limitation: this tool cannot fetch live URLs automatically (cross-origin restriction). For each row, paste the live SHA-256 hash you computed in the Verify tab above, or leave it blank to flag the row for manual follow-up.

    What This Check Does Not Tell You
    
      
      
        
    • Metadata can be stripped, forged, or never present in the first place — absence is not evidence of AI generation.
      • 
        
    • No OSINT / reverse image search is performed (would require sending the image to a third party).
      • 
        
    • No GAN-fingerprint, frequency-domain, or ML-based deepfake classifier is run in-browser; results here are metadata-only plus light heuristics.
      • 
        
    • A validated C2PA chain proves the declared source type came from that signer — it does not independently verify the signer told the truth.
